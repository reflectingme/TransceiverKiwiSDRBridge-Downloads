# Transceiver KiwiSDR Bridge Downloads

Public downloads and documentation for **Transceiver KiwiSDR Bridge** by GW3JVB.

Transceiver KiwiSDR Bridge is a Windows utility that lets supported radios and SDR software control a KiwiSDR browser page, so the KiwiSDR frequency and mode follow the connected radio.

## Download

The installer will be available from the **Releases** page:

<https://github.com/reflectingme/TransceiverKiwiSDRBridge-Downloads/releases>

Download the latest file named:

```text
Transceiver-KiwiSDR-Bridge-Setup-vX.X.X.exe
```

Then run the installer and follow the on-screen instructions.
